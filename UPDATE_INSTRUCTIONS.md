# Install version 9.0.3

Extract `NKPI_v903_Extract.zip` using Windows **Extract All**. Upload the extracted contents to the existing GitHub repository, replacing matching files and preserving folders. Keep `kcn_dual_calculator_app.py` as the Streamlit entry point. Reboot and refresh the app; confirm `9.0.3-cone-evolution` in the footer.

Reimport the original report ZIPs, calculate, then open **Regional change & 3D corneal view**. Select OD or OS. **Cone evolution tracker** compares two visits; **3D corneal view** works with one or two. The 3D panel offers **Cornea + eye** and **Cornea close-up**. Reference anatomy is explicitly labeled and does not affect NKPI.

The ZIP contains 99 files and uses ordinary DEFLATE compression. No new API key or dependency is required. Existing patient files are not included.
